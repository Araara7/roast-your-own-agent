## The roast

> I asked my agent for one line of roast; it drafted a plan, consulted three tools, and scheduled a committee meeting first.

## How it works

`main.py` writes the roast line to `/output/entry.txt` (122 characters, one line, deterministic).

Run it locally:

```sh
python3 main.py
cat /output/entry.txt
```
